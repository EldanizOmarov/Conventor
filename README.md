# File Studio

A free, no-signup file toolkit that runs entirely in your browser — no file is ever uploaded to a server.

**Live:** https://eldanizomarov.github.io/conventor/

## Features
- **Image converter** — convert between PNG, JPG and WEBP, resize, and compress. Batch convert to a ZIP.
- **To PDF** — turn images, plain text, Markdown, HTML and Word (`.docx`) into a single PDF.
- **PDF tools** — merge PDFs, select/delete/reorder/rotate pages, compress, and export pages as images.
- **PDF editor** — cover or erase text and images inside a PDF, and add your own text or images on top.
- 4 languages: AZ · EN · TR · RU.

## How to use
Open the site, pick a tab, drop your files, and download the result. Everything is processed locally in your browser.

## Notes
- Image → PDF and text/Word → PDF keep real text where possible.
- Merged and edited PDFs are rebuilt from high-quality page images (text is not selectable in the result).
